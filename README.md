# wardrobe

Оболочка приложения «Гардероб»: https://mary-jetmetrics.github.io/wardrobe/

Данных здесь нет — вещи и фото подтягиваются из закрытого репозитория `wardrobe-data` по ключу
доступа (fine-grained token), который вводится один раз на устройстве и хранится только в браузере.
`catalog.js` и `index.html` собирает `life/wardrobe/каталог/build_web.py` из шаблона локального каталога.
